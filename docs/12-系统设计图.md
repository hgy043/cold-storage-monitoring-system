# 12-系统设计图（Mermaid）

> 对应当前验收链路：virtual-server 转发程序 + ARM Cortex-A53 Linux 板 （LVGL）+ 华为云 IoTDA + H5 大屏。
> 在支持 Mermaid 的渲染器（Obsidian / GitHub / VS Code Markdown 插件）中可直接显示。

## 1. 流程图（系统数据流）

```mermaid
flowchart TD
    subgraph Cloud["华为云 IoTDA"]
        IOT["设备 yihao<br/>属性上报 / 命令下发"]
    end
    subgraph Ubuntu["Ubuntu 虚拟机"]

    end
    subgraph Board["gec6818 终端"]
        TCP["TCP 线程<br/>接收 virt_data"]
        UI["LVGL 界面<br/>5 页 SCADA"]
        HW["蜂鸣器 / LED<br/>/dev/beep + sysfs"]
    end

    VB -->|"MQTT 属性上报"| IOT
    IOT -->|"命令下发 set_led/set_beeper/..."| VB
    VB <-->|"本地 MQTT 1883<br/>数据 + 命令"| WEB
    VB -->|"TCP virt_data 帧 18830"| TCP
    TCP -->|"confirm / ack 帧"| VB
    TCP --> UI
    UI -->|"确认报警 / 按钮"| TCP
    UI --> HW
```

## 2. 时序图（上行数据 / 报警 / 下行命令）

```mermaid
sequenceDiagram
    autonumber
    participant VB as Ubuntu virtual_bridge
    participant IOT as 华为云 IoTDA
    participant WEB as H5 大屏 web
    participant TERM as ARM Cortex-A53 Linux 板 

    rect rgb(230,245,255)
    Note over VB,TERM: 上行数据流（每 3s）
    VB->>VB: stepZones 生成 4 温区数据
    par 三路分发
        VB->>IOT: MQTT properties/report
        VB->>WEB: 本地 broker report
        VB->>TERM: TCP virt_data 帧
    end
    TERM->>TERM: 解析 → 更新 UI / 报警判定 / 校时
    end

    rect rgb(255,235,235)
    Note over VB,TERM: 报警流程（每 2 分钟）
    VB->>VB: 制造报警 alarm=1 status=2
    VB->>TERM: virt_data alarm=1
    TERM->>TERM: 蜂鸣器响 + LED 亮
    TERM->>TERM: 巡查触摸 取消报警
    TERM->>VB: confirm 帧
    VB->>VB: alarmActive=false 计时复位
    end

    rect rgb(235,255,235)
    Note over IOT,TERM: 下行命令流（网页 / 华为云双入口）
    IOT->>VB: set_beeper 命令 request_id
    WEB->>VB: set_beeper 命令 request_id
    VB->>TERM: cmd 帧 cmd_id
    TERM->>TERM: 执行 ioctl 蜂鸣
    TERM->>VB: ack 回执
    VB-->>IOT: commands/response result_code=0
    VB-->>WEB: commands/response result_code=0
    end
```

## 3. 状态图（终端 + 转发程序）

```mermaid
stateDiagram-v2
    [*] --> 离线
    离线 --> 在线: TCP 连接 + register 注册
    在线 --> 离线: 断线(指数退避重连)
    在线 --> 正常: 收到 virt_data 无报警
    正常 --> 报警: alarm=1 或温区 status=2
    报警 --> 确认锁存: 触摸确认 / 云端 confirm_alarm
    确认锁存 --> 正常: 6s 锁存窗口结束
    报警 --> 报警: 蜂鸣持续 等待人工确认

    state 转发程序 {
        [*] --> 数据周期
        数据周期 --> 数据周期: 每3s 生成并三路推送
        数据周期 --> 报警激活: 满2分钟制造报警
        报警激活 --> 数据周期: 收到 confirm
        报警激活 --> 报警激活: 保持越限温度
    }
```

## 4. 类图（数据模型与模块接口）

```mermaid
classDiagram
    class ui_state_t {
        +ui_zone_t zones[4]
        +ui_energy_t energy
        +ui_system_t system
        +int led
        +int beeper
    }
    class ui_zone_t {
        +double temperature
        +double humidity
        +double setpoint
        +int status
    }
    class ui_energy_t {
        +double power_kw
        +double energy_kwh
        +int defrost
        +int condenser_fan
        +int door
    }
    class alarm_rec_t {
        +int level
        +char zone[20]
        +char desc[56]
        +char tstr[20]
        +int confirmed
    }
    class VirtualBridge {
        +zones[4] 温区状态
        +bool alarmActive
        +socket 终端TCP连接
        +mqttClient 华为云
        +localClient 本地broker
        +dataTick() 数据主循环
        +onCloudMessage() 云端命令
        +handleDeviceFrame() 终端帧
    }
    class Terminal {
        +tcp_thread 接收线程
        +g_alarm 报警状态
        +g_beep_manual 蜂鸣命令
        +apply_alarm() 声光驱动
        +handle_cmd() 命令执行
        +sync_clock_from_ts() 校时
    }
    ui_state_t --> ui_zone_t : 组合 4 温区
    ui_state_t --> ui_energy_t : 组合能耗
    Terminal --> ui_state_t : 喂数据快照
    Terminal --> alarm_rec_t : 产生报警记录
    VirtualBridge --> Terminal : TCP virt_data/confirm
    VirtualBridge --> Web : 本地 MQTT
    VirtualBridge --> IoTDA : MQTT 上报
```
