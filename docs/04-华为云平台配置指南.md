# 04-华为云平台配置指南（IoTDA）

> 本指南面向正式部署：gec6818 → Ubuntu 网关（C + AgentLite SDK）→ 华为云 IoTDA → H5 大屏。
> 本地演示（无云账号）不需要本指南，直接用 `web/server.js` 的内嵌 broker。

## 1. 开通与准备

1. 登录华为云控制台，搜索并开通 **IoTDA 设备接入服务**（基础版即可满足教学演示）。
2. 记录 **接入信息**：控制台 → 设备接入 → 总览/接入信息 → 复制 **MQTT 接入地址**，形如
   `<接入地址>.iotda-device.cn-south-4.myhuaweicloud.com`，端口 **8883**（TLS）。
3. 下载平台根证书（`conf/rootcert.pem`，SDK 包已附带，勿删）。

## 2. 创建产品（模型）

1. **产品** → 创建产品：协议 **MQTT**，数据格式 **JSON**，所属行业/设备类型自填（如"冷链物流"）。
2. 记录 **产品 ID**（形如 `f6cd4bbb1a8ab53acbb595efd0e90199`）。
3. 在产品的 **模型定义** 中添加服务 `coldstorage`（service_id 必须与本项目一致）：
   - 属性（properties，类型按括号）：
     - temperature 温度（decimal，范围 -50~50）
     - humidity 湿度（decimal，0~100）
     - led 指示灯（int，0/1）
     - beeper 蜂鸣器（int，0/1）
     - alarm 告警标志（int，0/1）
     - alarm_threshold 报警阈值（int，可读写）
   - 命令（commands）：
     - set_led：入参 on（int）
     - set_beeper：入参 on（int）、duration_ms（int）
     - set_interval：入参 seconds（int）
     - set_alarm_threshold：入参 value（int）

## 3. 注册设备

1. **设备** → 注册设备：
   - 所属产品选上一步的产品；设备标识（deviceId）形如 `f6cd4bbb1a8ab53acbb595efd0e90199_gateway01`（网关，直连）。
   - 认证方式选 **密钥**，自定义密钥（secret），记录 deviceId/secret → 填入 `gateway/ClientConf.json`。
2. 子设备：可在"设备 → 子设备"下为每个冷库节点注册子设备（deviceId = `{产品ID}_cold01_front` 等），
   也可以由网关通过子设备管理（`IOTA_SubDeviceInfoReport` / add_sub_device_notify）动态注册。
   本项目的 `subDeviceIdPrefix` 配置即用于拼接：`{subDeviceIdPrefix} + node_id`。

## 4. 规则引擎（告警联动，可选）

控制台 → 规则 → 数据转发/设备联动：

- 规则示例：服务 `coldstorage` 属性 `temperature` > `alarm_threshold` 时，
  触发 **发送通知**（短信/邮件）或调用函数/转发到应用侧。
- 也可用平台的"设备联动"规则：上报温度异常时向网关下发 set_beeper 命令，实现云端自动告警。

## 5. 应用侧对接（H5 大屏两种方式）

| 方式 | 说明 | 适用 |
|---|---|---|
| A. 订阅 AMQP 消息推送 | 平台"数据转发规则"把设备属性上报推送到 AMQP 队列，应用消费 | 生产级 |
| B. 直接查询 API | 调用 IoTDA 查询设备属性/消息记录 REST API（AK/SK 签名，见 API Explorer） | 简单场景 |
| C. 本项目演示 | `web/server.js` 内嵌 broker + 网关直连，不依赖云账号 | 教学/联调 |

本项目 `web/server.js` 已实现 C（订阅上报 topic），部署到真实云时：
把 `node-gateway/conf.json` 的 broker 改为 `ssl://{接入地址}:8883`、deviceId/secret 改为真实值，
或直接运行 C 网关，`web/server.js` 作为应用侧即可收到真实数据（无需改代码）。

## 6. 排查

- 鉴权失败（`IOTA_MQTT_CONNECT_FAILED`）：检查 deviceId/secret 是否与平台一致、是否含下划线格式错误。
- 设备在线但数据不上屏：检查产品模型 service_id 是否 `coldstorage`、属性名是否与上报 JSON 一致。
- 命令下发无响应：确认设备已注册且在线；request_id 必须回填到响应 topic。
